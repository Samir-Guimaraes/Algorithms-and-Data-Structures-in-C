# Algorithms and Data Structures in C

A collection of algorithms, data structures, and computational problem-solving techniques implemented in the **C programming language**.

This repository is part of my technical development in **Computer Science**, with a focus on understanding how algorithms and data structures work internally rather than simply relying on ready-made abstractions.

---

## Objectives

This repository aims to:

- Strengthen my knowledge of the C programming language.
- Develop a deeper understanding of algorithms and data structures.
- Practice pointers and dynamic memory management.
- Implement classical and advanced algorithms from scratch.
- Analyze algorithmic complexity and performance.
- Develop problem-solving and computational thinking skills.
- Build a solid foundation for more complex C projects.

## Approach

The implementations in this repository are developed with an emphasis on:

- understanding the underlying logic of each algorithm and data structure;
- implementing data structures manually;
- understanding and manipulating pointers;
- managing memory dynamically;
- analyzing algorithmic efficiency;
- studying time and space complexity;
- writing organized and readable code;
- understanding the trade-offs between different approaches.
